# Ярмарочный бот — настройка и запуск

Клиентский Telegram-бот `@yourtailbot` + оплата ЮKassa. Реализация — по [FAIR-BOT-PROMPT.md](FAIR-BOT-PROMPT.md).

## 1. Бот уже создан

- Токен: в `.env.local` как `TELEGRAM_CLIENT_BOT_TOKEN`.
- Username: `TELEGRAM_CLIENT_BOT_USERNAME=yourtailbot`.
- Если нужен другой бот — создайте у [@BotFather](https://t.me/BotFather) командой `/newbot`, впишите токен и username в `.env.local`.

## 2. Переменные окружения

Уже в `.env.local`:

```
TELEGRAM_CLIENT_BOT_TOKEN=...
TELEGRAM_CLIENT_BOT_USERNAME=yourtailbot
TELEGRAM_CLIENT_WEBHOOK_SECRET=...   # сгенерирован случайно
FAIR_TSHIRT_PRICE_RUB=5000
FAIR_SEND_RECEIPT=false              # true — если нужен чек 54-ФЗ в ЮKassa
FAIR_VAT_CODE=1
FAIR_ENABLED=true
```

ЮKassa (ключи уже есть, но выключена):

```
YOOKASSA_SHOP_ID=1389709
YOOKASSA_SECRET_KEY=live_...
YOOKASSA_ENABLED=false   # включить после настройки уведомлений (шаг 4)
```

## 3. Вебхук Telegram

После деплоя (или на живом сервере):

```bash
node scripts/telegram-set-webhook.mjs --client
```

Проверить: `getWebhookInfo` в выводе должен показывать `url: https://dogood-brand.ru/api/telegram/client-webhook` без ошибок.

## 4. Уведомления ЮKassa (HTTP-нотификации)

1. Зайдите в [личный кабинет ЮKassa](https://yookassa.ru/my) → магазин `1389709`.
2. Раздел **Интеграция → HTTP-уведомления**.
3. URL: `https://dogood-brand.ru/api/payments/yookassa/webhook`
4. Отметьте события: `payment.succeeded`, `payment.canceled`.
5. Сохраните.
6. После этого поставьте `YOOKASSA_ENABLED=true` и `NEXT_PUBLIC_YOOKASSA_ENABLED=true` в `.env.local` на сервере и перезапустите приложение.

Даже если уведомление придёт с опозданием или потеряется — каждый крон-тик (`runStudioPipelineTick`) сам перепроверяет платежи со статусом `pending` за последние 6 часов через `pollPendingFairPayments()`, так что оплата всё равно будет засчитана.

## 4b. Чеки самозанятого («Мой налог»)

После каждой успешной оплаты бот автоматически регистрирует доход в «Мой налог»
(lknpd.nalog.ru) и присылает клиенту ссылку на чек. Для включения добавьте в
`.env.local`:

```
MOY_NALOG_INN=ваш ИНН
MOY_NALOG_PASSWORD=пароль от lknpd.nalog.ru
```

Пароль — тот же, что для входа на сайт lknpd.nalog.ru (НЕ пароль от Госуслуг;
если входите только через Госуслуги, задайте пароль в настройках кабинета).
Пока переменные не заданы, чеки просто не отправляются — оплата работает как раньше.

Если регистрация чека не удалась (сервис недоступен, неверный пароль), заказ
не страдает: бот пришлёт вам предупреждение, а крон будет повторять попытку
(до 5 раз). После исчерпания попыток чек нужно оформить вручную в приложении
«Мой налог».

## 4a. Производительность на потоке (параллельные дорожки)

Генерации выполняются параллельно: иллюстрация собаки и иллюстрация клички одного заказа готовятся одновременно, и заказы разных клиентов тоже идут одновременно. Одновременных «дорожек» по умолчанию 4 — то есть примерно два клиента обрабатываются полностью параллельно.

Если на ярмарке очередь и хочется быстрее, поднимите лимит в `.env.local` и перезапустите приложение:

```
STUDIO_MAX_CONCURRENT_LANES=6
```

Больше 12 поставить нельзя (защита от перегрузки OpenRouter). Количество обращений к ИИ не меняется — меняется только их одновременность, поэтому стоимость генераций остаётся прежней. Если появятся ошибки от провайдера (rate limit), снизьте значение обратно до 4.

Крон запускает обработку раз в минуту, плюс она стартует мгновенно после каждого вашего одобрения или комментария к доработке — ждать крон не нужно.

## 5. Прогон перед мероприятием

Сухой прогон без реальных обращений к Telegram/ЮKassa (Google Drive/Sheets всё ещё реальные, как и в существующем `studio-mock-e2e.ts`):

```bash
npx tsx --conditions react-server scripts/fair-mock-e2e.ts
```

Ожидаемый результат в конце: `FAIR E2E MOCK TEST PASSED ✅`.

Отдельная проверка параллельной обработки (три клиента одновременно, без перепутывания собак и кличек):

```bash
npx tsx --conditions react-server scripts/fair-parallel-e2e.ts
```

Ожидаемый результат: `FAIR PARALLEL E2E TEST PASSED ✅`.

Живой прогон (по-настоящему, с реальными ботами и оплатой):
1. Откройте `https://t.me/yourtailbot`, нажмите `/start`.
2. Пришлите тестовое фото собаки, кличку, email.
3. В боте владельца (`TELEGRAM_CHAT_ID`) придут собака и кличка на проверку — одобрите обе.
4. Придёт финальный макет на проверку — одобрите.
5. В клиентском боте появится макет + кнопка оплаты. Оплатите тестовую сумму (или временно поставьте `FAIR_TSHIRT_PRICE_RUB=1` для дешёвого теста).
6. После оплаты бот спросит размер/ФИО/телефон/доставку/ПВЗ — заполните.
7. Проверьте, что в основной таблице заказов появилась новая строка с пометкой «ЯРМАРКА» в колонке «Комментарий».

## 6. На самом мероприятии

- Повторный `/start` с одного Telegram-аккаунта даёт вежливый отказ — один бесплатный макет на аккаунт.
- Если генерация зависла или упала — все шаги видно в `/studio/orders` (админка), заказ помечен `mode: fair`.
- Алерты о новых заявках, оплатах и записи в таблицу приходят в бот владельца (`TELEGRAM_CHAT_ID`).
