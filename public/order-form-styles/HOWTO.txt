Макеты превью в форме заказа (блок «Стиль принта»)
==================================================

Положите файл с именем **2** в каждую папку:

  public/order-form-styles/life/2.png   → «Life is better»
  public/order-form-styles/speed/2.png  → «Я — скорость»
  public/order-form-styles/rainy/2.png  → «No rainy days»

Допустимы расширения: .png, .jpg, .webp (в коде сейчас .png).

После замены файлов на сервере: git push + docker build (см. DEPLOY-TIMEWEB.md).

Проверка в браузере:
  https://dogood-brand.ru/order-form-styles/life/2.png
  (должна открыться картинка, не 404)
